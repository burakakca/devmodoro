# Audio Assets

Place the following audio files in this directory:

## Required Files

| File | Description | Recommended Duration |
|------|-------------|---------------------|
| `rain.mp3` | Rain ambient sound | 30-60 seconds, seamless loop |
| `fire.mp3` | Fireplace/crackling fire | 30-60 seconds, seamless loop |
| `coffee.mp3` | Coffee shop ambience | 30-60 seconds, seamless loop |
| `alarm.mp3` | Timer completion sound | 1-3 seconds |
| `tick.mp3` | Ticking clock sound | ~1 second, seamless loop |

## Recommendations

- Use MP3 format for best browser compatibility
- Ensure ambient sounds loop seamlessly (no audible gap)
- Keep alarm sound short and attention-grabbing
- Consider file size - compress for web delivery
